# Рабочее место курса в облаке

Это готовое рабочее место для курса: Claude Code, Python, Node и браузер для проверок
уже установлены. Работает в вашем браузере, на компьютер ставить ничего не нужно.
Подходит, если на вашем компьютере Claude Code не устанавливается: 32-разрядная
Windows, старая система, рабочий компьютер без прав администратора, слабый ноутбук.

## Как получить своё рабочее место

1. Зарегистрируйтесь на github.com, если аккаунта ещё нет. Это бесплатно.
2. На странице этого шаблона нажмите зелёную кнопку **Use this template** →
   **Create a new repository**. Назовите репозиторий `kurs`, выберите **Private**
   и нажмите **Create repository**. Теперь у вас своя копия.
3. В своём репозитории нажмите зелёную кнопку **Code** → вкладка **Codespaces** →
   **Create codespace on main**.
4. Подождите три-пять минут: собирается среда и ставятся программы. Откроется
   редактор, внизу терминал. Если терминала нет, нажмите три полоски слева
   вверху → **Terminal** → **New Terminal**.
5. В терминале напишите `claude` и нажмите Enter. Выберите вход через подписку,
   откройте предложенную ссылку в новой вкладке, войдите в аккаунт Claude и вставьте
   полученный код обратно в терминал.
6. Напишите Claude: **проверь рабочее место**. Он покажет, что установлено, и
   доставит недостающее сам.

Дальше работайте по инструкции курса для Mac: внутри обычный Linux, команды те же.

## Как сюда ставить скиллы курса

Перетащите архив скилла из урока в проводник слева (панель с файлами) и напишите
Claude: **поставь этот скилл**. Он распакует архив куда нужно. После этого выйдите
из Claude командой `/exit` и запустите `claude` снова: список скиллов читается при
запуске.

## Три вещи, которые нужно знать

**Среда засыпает** через 30 минут без действий. Это нормально. Зайдите на
github.com/codespaces и откройте её снова, все файлы на месте.

**Среда удаляется** через 30 дней без заходов. Чтобы этого не случилось, на
github.com/codespaces нажмите «…» рядом с ней и выберите **Keep codespace**.
А работу закрепляйте в репозитории: напишите Claude «сохрани работу», он сделает
commit и push.

**Бесплатных часов** на личном аккаунте GitHub хватает примерно на 60 часов работы
в месяц. Счётчик обнуляется в начале каждого месяца. Не оставляйте среду открытой
без дела и не выбирайте машины мощнее двух ядер, они тратят часы быстрее.

## Где что лежит

```
proekty/          сюда складываются сайты, боты и другие работы, каждая в своей папке
.claude/skills/   скиллы: один уже есть, остальные ставите из уроков
.devcontainer/    описание среды, менять не нужно
```

## Как скачать сделанное на свой компьютер

Правый клик по файлу или папке в проводнике слева → **Download…**. Посмотреть
собранный сайт: попросите Claude «открой сайт в браузере», он поднимет его и даст
ссылку во вкладке «Порты».
