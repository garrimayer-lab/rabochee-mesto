# Рабочее место курса в Codespaces

Ты работаешь внутри GitHub Codespaces: это Linux-машина в облаке, ученик видит её
через браузер. На его собственном компьютере ничего не установлено, и ставить туда
ничего не нужно. Все пути, команды и инструкции курса «для Mac» подходят здесь без
изменений.

## Проверка по команде «проверь рабочее место»

Выполни и покажи результат одной таблицей «что · версия · статус»:

```bash
claude --version
node --version
python3 --version
git --version
python3 -c "import playwright; print('playwright есть')"
ls ~/.cache/ms-playwright 2>/dev/null | head -3
```

Если Playwright или браузер Chromium не стоят, поставь сам, не спрашивая:

```bash
python3 -m pip install --user playwright
python3 -m playwright install --with-deps chromium
```

Если `claude` не найден, значит `~/.local/bin` выпал из PATH:

```bash
export PATH="$HOME/.local/bin:$PATH"
grep -q 'HOME/.local/bin' ~/.bashrc || echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
```

## Установка скилла из архива курса

Ученик перетаскивает `.zip` в проводник слева. Распакуй его в `.claude/skills/<имя>/`
так, чтобы `SKILL.md` лежал прямо в папке скилла, а не во вложенной. Файл из папки
`agents/` внутри архива, если он есть, скопируй в `.claude/agents/`. Архив после
распаковки удали. Скажи ученику: скилл подхватится после перезапуска Claude Code,
то есть достаточно выйти командой `/exit` и снова написать `claude`.

Скиллы в `.claude/skills` этого репозитория живут вместе с проектом и переживают
пересоздание среды. В `~/.claude/skills` ничего не клади: при пересборке контейнера
эта папка стирается.

## Где лежат проекты

Сайты, боты и прочие работы создавай в папке `proekty/`, каждую в своей подпапке.
Так ученик видит всё в одном месте, и всё это попадает в его репозиторий при
сохранении.

## Сохранить работу и скачать файлы

Codespaces хранит файлы между запусками сам. Но среда удаляется после 30 дней без
заходов, поэтому раз в занятие предлагай закрепить работу в репозитории:

```bash
git add -A && git commit -m "занятие: что сделано" && git push
```

Скачать файл или папку на свой компьютер: правый клик по файлу в проводнике слева,
пункт «Download…». Открыть собранный сайт глазами: `python3 -m http.server 8080` в
папке сайта, затем вкладка «Порты» внизу и кнопка «Открыть в браузере» напротив 8080.

## Типовые поломки

- **Среда уснула.** После 30 минут без действий Codespaces останавливается. Это не
  потеря: ученик открывает github.com/codespaces и запускает её снова, файлы на месте.
- **Удалилась через 30 дней.** Если репозиторий сохранён через git push, всё
  восстанавливается созданием новой среды из него же. Чтобы этого не случалось,
  на github.com/codespaces у среды нажать «…» → «Keep codespace».
- **Кончились бесплатные часы.** Личный аккаунт даёт 120 часов в месяц с множителем
  по ядрам: на двухъядерной машине это 60 часов. Счётчик обнуляется в начале месяца.
  Не держать среду открытой без дела и не выбирать машины на 4 и больше ядер.
- **Вход в Claude не проходит.** `claude` печатает ссылку и ждёт код. Ссылку открыть в
  новой вкладке того же браузера, войти в аккаунт Claude с подпиской, скопировать код
  и вставить в терминал. Если сессия браузера на github.com и claude.ai в разных
  профилях, вход не свяжется: открыть обе в одном окне.
